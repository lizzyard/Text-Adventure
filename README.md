# Text-Adventure
A simple game where the player moves between rooms, collects items, and uses an inventory

commands:
- Forest, Town, Cave, Castle
Allows the player to move to different areas as long as it is a room the player can move to

- look
Allows the player to see what room they are in, connected rooms, and total moves they made

- exit
Exits the game

- inventory
Allows the player to view items in their inventory
